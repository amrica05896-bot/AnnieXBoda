## 💎 What is Source Venom? (Glass Edition)

**Source Venom** is a Next-Gen Telegram bot designed to stream **ultra-high-quality music** directly into your group voice chats. 
Built on a modern **Native Async Architecture (Pyrogram + PyTgCalls 3.x)**, it features a stunning **Glass-morphism UI** for thumbnails and supports multi-platform streaming including **YouTube, Spotify, SoundCloud, and Apple Music**.

## 🔑 Environment Variables

To run the Venom bot, configure the following variables in your `.env` file:

```env
API_ID=              # Required - Get from [https://my.telegram.org](https://my.telegram.org)
API_HASH=            # Required - From [https://my.telegram.org](https://my.telegram.org)
BOT_TOKEN=           # Required - Get from t.me/BotFather
OWNER_ID=            # Required - Your Telegram user ID
LOGGER_ID=           # Required - Log group/channel ID (Start with -100)
STRING_SESSION=      # Required - Generate from @SessionBuilderbot
MONGO_DB_URI=        # Required - MongoDB connection string
COOKIE_URL=          # Optional - YT Cookies url (Pastebin raw link)
