## 🚀 Why Source Venom?
Source Venom is built for absolute stability and zero-latency audio streaming in Telegram Voice Chats. No cluttered UI, just pure performance.

* 🎧 **Ultra-Fast Streaming** (Powered by PyTgCalls 3.x)
* 🌐 **Multi-Platform** (YouTube, Spotify, Apple Music, SoundCloud)
* 🎛 **Advanced Queue & Management** (Seamless control for admins)
* ⚡ **Python 3.13 Optimized** (Lightweight and highly efficient)

## ⚙️ Environment Variables (.env)
Keep your credentials safe. Fill these in your deployment environment:

```env
API_ID=              # From my.telegram.org
API_HASH=            # From my.telegram.org
BOT_TOKEN=           # From @BotFather
OWNER_ID=            # Your Telegram ID
LOGGER_ID=           # Log Channel ID (Starts with -100)
STRING_SESSION=      # From @SessionBuilderbot
MONGO_DB_URI=        # MongoDB Connection String
